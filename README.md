Пример реализации паттерна Composite (Компоновщик). 
Состоит из трёх основных компонентов: Интерфейс, и два класса, которые его имплементируют: 
Один класс имеет список элементов интерфейса и используется в качестве "веток" в древовидной структуре (пример - папка)
Второй класс не имеет дочерних элементов этого интерфейса и используется в качестве "листьев" в древовидной структуре (пример - файл)
